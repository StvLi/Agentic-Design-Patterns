## 二、推荐顺序：按章走，1 → 5

理由：**这些 lab 本身就是按书的递进写的**。每份的 §0 都是环境自检，§1 都从最基础的一步开始，
跳跃着做会撞见"上一章才建立的概念"。

```
Ch1（链的机制）
  → Ch2（路由：分类 + 归一化）
  → Ch2_4（路由的框架版：从 if/else 到 RunnableBranch）
  → Ch3（并发与失败传播）
  → Ch4（反思的有效性 —— 最重、最有实验价值）
  → Ch5（工具循环）
```

## 四、时间有限时的"精华路线"（约 60–75 分钟）

## 五、第 6、7 章的缺口

这两章**没有配套 lab**，只有注释版 notebook。如果之后想做实验，建议补这三个（都不大）：

1. **Ch6**：同一个 task，一次让计划留在 prose 里，一次用 `output_pydantic` 收成
   `list[str]`——对比"计划是散文"和"计划是数据"能做的事（约 20 行）。
2. **Ch6**：`planning=True`（CrewAI 原生规划开关）和书里"把计划写进 task"两条路的输出对比。
3. **Ch7**：两个 agent 写同一个 `output_key`，串行 vs 并行各跑 3 次，
   观察 last-write-wins 和竞态（这个实验我已经跑过，结论在 `ch07_notes_communication.md`）。
